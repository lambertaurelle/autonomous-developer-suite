# Implementation Plan - Reusable Agentic Blueprint V3 Suite (v4.0 Production Grade)

Build a complete, production-grade, and reusable suite combining **Antigravity Rules, Workflows, Skills, and Hooks**, along with project constitution (`AGENTS.md`) and an automated bootstrap script (`scripts/init-project.sh`) based on the **Architecture Blueprint: Autonomous Development Driven by AI Agents (V3)** PRD (`agentic-blueprint.md`), official **Google Antigravity & Gemini Cookbook** standards, and key best practices from **[lambertaurelle/agentic-dev-plugin](https://github.com/lambertaurelle/agentic-dev-plugin)**.

## Key Architectural Principles & Best Practices Integrated

> [!IMPORTANT]
> **"A Skill Asks; A Hook Imposes"**
> - **Skills (Method)**: Carry judgment and workflow procedures, invoked from the CLI or orchestrator.
> - **Hooks (Enforcement)**: Deterministic, zero-token CLI gates running outside the LLM loop that block on non-zero exits (linting, pytest/jest, test coverage ≥ 90%, Trivy security scans).

> [!NOTE]
> **End-to-End Rule Traceability**
> - Every commit generated by `/ship` or `/commit` enforces the traceability format: `type(scope): summary [Rn] (#issue_id)`.
> - Establishes 100% auditability: **PRD Rule [Rn] ↔ Issue (#xxx) ↔ Spec ↔ Code ↔ Unit Test ↔ Commit ↔ Runtime**.

> [!TIP]
> **Persona-Based Skill & Workflow Division**
> - **Product Owner Persona**: `/interview-prd`, `/audit-prd`, `/prd2backlog` (upstream scoping, 360° grid audit, backlog generation).
> - **Engineering Persona**: `/arch-gate`, `/specify`, `/review-spec`, `/tdd-build`, `/e2e-test`, `/ship` (architecture locking, contract-first TDD, Playwright browser E2E, rule-linked shipping).
